📱 Install App

Install KalpaKuber to your home screen for a full-screen, app-like experience that works offline. On Android/Chrome, tap the button below (or use the browser's "Add to Home Screen" from the ⋮ menu). On iPhone/Safari, tap the Share icon → "Add to Home Screen".

🔗 Local Folder Sync

Link a folder on your device and every change auto-saves to a kalpakuber-data.json file there — no manual downloads, no risk of losing data if the browser cache is cleared. Works on Chrome / Edge on laptop and Android; not supported on iOS Safari or Firefox (use Export/Import there instead).

Not synced

Your browser doesn't support the File System Access API — folder sync isn't available here. Use Export/Import instead.

Data

Everything is saved locally in this browser. Export regularly so you never lose it.

Import accepts .json (a full KalpaKuber backup, or a plain list of records), .csv, or .xlsx / .xls. Only a Name column is required — Phone, Source, Stage, Value, Next Action, Follow-up Date, Renewal Date, Birthday, Tags, Status and Notes are matched automatically if present, under common header names. Anything we can't recognize is kept in Notes so no data is lost — you (or someone you hire) can fill the rest in by hand afterward. CSV/Excel exports are free anytime — your data is never locked in.

✉️ Communication Templates

Pre-fill WhatsApp messages for renewals, greetings and follow-ups. Use {name}, {value}, {renewalDate}, {nextAction} as placeholders — they're filled in automatically when you send from a Lead or Client.
